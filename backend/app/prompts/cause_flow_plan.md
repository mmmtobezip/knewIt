# 지시
fetch_indicator와 search_news 도구를 사용해 이 변동의 원인을 파악하기 위한 데이터를 수집하라.

- **fetch_indicator**: 이 변동과 인과관계가 있을 법한 상위 원인 지표 조회
- **search_news**: 변동의 원인이 될 수 있는 현상으로 뉴스 검색

## 수집 기준
1. 원인 지표 2~3개 조회
   - 예: 열연 가격 하락 → 철광석, 원료탄, 중국 HR 수출가 조회
   - 예: 철광석 하락 → 중국 조강생산량, BDI 해운운임 조회
2. 변동 원인이 될 수 있는 현상으로 뉴스 2~3회 검색
   - 지표명을 그대로 검색하지 말 것 (예: "철광석 CFR China" → X)
   - 변동의 원인이 되는 현상으로 검색 (예: "중국 부동산 침체", "iron ore demand China")
   - 한국어 키워드 1~2회 + 영어 키워드 1회 권장
3. 충분한 데이터가 모이면 종료

## 절대 금지
- 같은 지표/키워드 중복 조회
- 5회 초과 도구 호출
