# 지시
질문에 정확히 답하기 위해 필요한 지표와 뉴스를 아래 도구로 수집하라.

- **fetch_indicator**: 특정 지표의 최신 값과 변동률 조회
- **search_news**: 한국어 키워드로 관련 뉴스 검색 (예: "열연 가격 하락", "중국 철강 수요")

## 수집 기준
1. 질문에서 언급된 지표·현상과 직접 관련된 지표 2~4개 조회
2. 질문의 핵심 주제로 뉴스 1~2회 검색
3. 고객사 업종·지역이 관련있다면 해당 맥락의 지표도 포함
4. 충분한 데이터가 모이면 도구 호출을 멈추고 종료

## 절대 금지
- 확실하지 않은 지표명 추측 금지
- 같은 지표 중복 조회 금지
- 5회 초과 도구 호출 금지
