## 3. 문제 정의

### 현재 업무 수행 방식

POSCO 철강 판매담당자는 매일 아침 거래처 응대 준비를 위해 다음을 **수동·분산** 형태로 수행:

1. MIH 시스템에서 시황 지표 10여 개를 따로 확인 (**30분/일**)
2. ERP/엑셀로 당월 가이드값 vs 누적 실적 / 전년 동월 대비 수기 합산
3. 본인 메모/엑셀로 거래처별 산업 특성·민감 이슈·과거 패턴 검색
4. 머릿속에서 종합 → 직관·경험 기반 응대 결정

### 기존 방식의 불편함 / 비효율

- **시간 낭비**: 5명 × 30분 × 240영업일 = **연 6,000시간** 비생산적 소비
- **인사이트 단절**: 시황 ↔ 자사 실적 ↔ 거래처 컨텍스트가 3개 분리 시스템
- **재현성 부재**: 직관·경험 기반 → 베테랑·주니어 응대 품질 격차
- **가이드값 추적 부재**: 월말이 되어서야 미달 거래처 발견 → 선제 대응 불가
- **노하우 사장**: 영업사원이 엑셀에 보유한 노하우가 조직 자산화되지 못함
- **도메인 지식 단절**: 산업별 베스트프랙티스 / 거래처별 과거 응대 사례를 *실시간 검색* 불가 — RAG 부재로 LLM 호출 시 매번 정적 프롬프트만 사용

### 이 문제를 해결해야 했던 이유

**5명 판매담당자 1차 인터뷰**에서 동일 키워드가 5건 모두 등장:
*"시간 부족", "통합 인사이트 부재", "가이드값 추적 어려움", "거래처 우선순위 판정 곤란", "노하우 전산화 불가"*.

→ POSCO 마케팅 DX 전환의 핵심 병목이 **판매담당자의 일일 의사결정 지원** 임을 확인.
*RAG 기반 도메인 지식 검색 + LangGraph Agent로 다단계 추론* 이 이 병목 해소의 정공법.

## 4. 기대 효과

### 4.1 정성적 기대 효과

| 영역 | 변화 |
|---|---|
| **업무 방식** | 분산 모니터링 → 단일 RAG 검색 기반 대시보드. *시황·실적·거래처 컨텍스트 1화면 융합* |
| **사용자 경험** | "오늘 무엇을 할지" 가 매일 자동 추천 (오늘의 추천질문 3개 — RAG 컨텍스트 보강). 거래처 카드 클릭 → 4종 컨텍스트 (고객사 + 실적 + 시황 + 과거 패턴) 기반 3~4줄 행동 지침 즉시 생성 |
| **협업** | 같은 화면을 두고 동료·매니저와 토의 가능 → 노하우 공유 자연스러워짐 |
| **품질** | LangGraph StateGraph 5단계 Agent 순차/조건부 호출 + RAG 도메인 지식 주입 → 거래처에 *근거 있는* 응대 |
| **의사결정** | 거래처별 종합 스코어로 *우선순위 즉시 판정* — A/B/C 등급 카운팅 |


### 4.2 정량적 기대 효과

| 항목 | 기존 | 개선 후 | 산정 기준 |
|---|---|---|---|
| **일일 시황 모니터링 시간** | 30분/인 | **1분** (1분 브리핑 1장) | 인터뷰 5건 평균 |
| **연간 시간 절감 (마케팅실 5명)** | 0 | **6,000시간/년** | 30분 × 5명 × 240영업일 |

| **가이드값 미달 발견 시점** | 월말 (D-1) | **실시간** (당월 누적 신호등) | 모듈 1 일일 자동 판정 (≥80/50-79/<50) |

| **거래처 등급 다음 달 실적 일치율** | - | **85% 이상** (목표) | M2 종합 스코어 등급 (A/B/C) 이 다음 달 실 달성률 구간 (≥80/50-79/<50) 과 일치하는 비율 — 6개월 백테스트 |
| **신규 입사자 OJT 기간 단축** | 3개월 | **2주 (-90%)** (목표) | 베테랑의 거래처별 sensitive_topics / risk_factors / 시황 인과 흐름이 시스템에 영속화되어 신규 인력이 즉시 활용 가능 |
